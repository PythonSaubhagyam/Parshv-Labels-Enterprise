# Garment Label React Website

A responsive React + Vite garment-label company website using a yellow, white and black theme.

## Navigation
Home, About, Contact, Product, Quality, Blog, Carrer

## Current scope
The Home page is fully designed with sections for:
- Hero
- Brand introduction
- Product collection
- Quality
- About
- Blog
- Career
- Contact
- Footer

The navbar links scroll to the corresponding sections so the complete home-page UI can be demonstrated now.

## Run
```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Build
```bash
npm run build
```

## Notes
- React + Vite
- Responsive design
- Normal CSS
- lucide-react icons
- Yellow / white / black visual theme
- No backend or database
